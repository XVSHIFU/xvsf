## 项目目标

使用 EVE-NG 构建总部、数据中心、IaaS 模拟云侧及分支互联实验。课程拓扑作为地址和协议参考，以 OSPF/BGP 分层路由、Viptela SD-WAN、DMVPN/IPsec、vManage 集中管理和云侧动态互联为主线。

SD-WAN 与 DMVPN 通过混合业务网关为同一客户端提供按目的网段分流和故障互备。IaaS 运行轻量模拟 ERP 订单服务，采用 SQLite 数据迁移和保留 DC 原入口的方式演示云化访问。vManage 已用于 SD-WAN 管理；DNA Center 管理仍为目标缺项，SDA 不在范围。安全控制按实际配置记录，成本、效率和等保结论不凭连通结果推定。

## 实施范围

| 内容 | 范围 |
|---|---|
| 园区与站点互联 | 总部二层接入、双网关、集中 DHCP、OSPF 与 DC 互联 |
| 跨域路由 | AS65001/65002/65003、运营商承载、BGP 策略与云侧动态路由 |
| SD-WAN | 真实 vManage、vBond、vSmart、vEdge，控制连接、模板下发、业务 VPN 与基本连通 |
| 传统分支 | DMVPN、IPsec、EIGRP、HSRP 与终端接入 |
| 适度扩展 | 保留已完成的 IPv6、MPLS VPN、Guest 隔离/PAT、RESTCONF 与配置备份 |
| 不纳入本项目 | SDA Fabric、ISE 集成、VN 自动下发和 Fabric Host Onboarding |

不新增大型平台或独立 G7 故障矩阵。以配置生效、必要邻接、基本业务可达及已有冗余证据为完成依据，不追求精确切换计时和反复故障演练。

| 分区 | 当前职责 |
|---|---|
| Headquarters 总部 | AS65001；交换接入、网关冗余、OSPF、IPv6 EIGRP |
| Datacenter 数据中心 | AS65002；集中服务、SD-WAN 控制器、中心 Edge、DMVPN Hub、互联网出口 |
| IaaS 云侧 | AS65003；模拟云路由与终端；r30-IOL-IPv6 承担 IPv4/IPv6 云侧动态路由，r30-CSR-G6 承担运维功能 |
| Global SP1/SP2、Internet SP | 承载跨站路由与 SD-WAN 传输，提供模拟公网目标 |
| Branch 1/2 | 真实 vEdge41、vEdge51/vEdge52；通过 SP2 接入，保留普通业务接入，不建设 SDA |
| Branch 3/4 | DMVPN/IPsec、动态路由、终端接入与分支网关冗余 |

vEdge41 对应课程 vEdge40 角色。SP2 传输分别使用101.40.0.0/30、101.51.0.0/30、101.52.0.0/30。VPN0 为传输，VPN512 为管理；已实施 VPN199 Guest 业务及 VPN198/200/999 路由策略。VPN200 已接入两个员工终端，Branch 2 使用双 Edge VRRP 网关；VPN198仅保留路由策略。

## 当前进度与收尾

以 项目进度表 为统一进度入口，各阶段正文保留实际命令、截图和结果。G2/G3/G4 的主要网络功能与 G6 运维扩展已有实施证据；G5 已完成真实控制器、五台 Edge、课程 SP2 路径、DC 服务侧 OSPF、模板与路由策略。

G3 已补齐总部、DC 与 IaaS 的 IPv4 BGP 双向互通，原 IPv6 路径保留；G5 已补齐 VPN200 员工接入、跨分支和 DC 通信，以及 Branch 2 VRRP 网关。命令、实测结果和截图已写入对应笔记。云侧已增加 HTTPS/SQLite 模拟 ERP 服务并完成数据迁移；G5 已补充混合路径互备，G6 已补充业务自动诊断。DC vEdge 的 OMP 外部路由规则已同步至 vManage，两台模板下发成功，业务恢复正常。

## 运行与保存

管理入口 http://192.168.1.19；工作副本 `CCIE-EI-Course-Work/CCIE_EI_Lab_Classic_Part.unl`。现有50台节点不要求同时运行；按业务依赖启动。EVE 分配16GB内存、8 vCPU，宿主机约32GB内存，采用分阶段运行。
